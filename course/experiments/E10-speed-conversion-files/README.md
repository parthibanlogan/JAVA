# Experiment 10: Converting Speed Units (km/h to m/s) with File Input and Output

## Problem statement (syllabus)
Nick is developing a program to convert speed units from kilometers per hour (km/h) to meters per second (m/s). Create a file named `data.txt` to store the input speed in km/h. Read the speed from `data.txt`, convert it to m/s using Speed (m/s) = Speed (km/h) × (5) / 18, write the converted speed to `converted.txt`, and display it.

## Sample input and expected output

These cases are checked automatically on the JDK by `tools/CourseCheck.java`.

**Case 1**

Input:

```text
72.0
```

Output:

```text
20.00
```

## Run on your computer

```bash
javac Main.java
java Main < input.txt
```

Or type the input yourself after `java Main`.
