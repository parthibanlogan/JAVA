Teacher tools

Everything on this page runs in your browser. Keys and decrypted submissions are never sent anywhere. Step-by-step instructions: Guide 10: Java Lab assessments.

1. Create the submission key pair (once)

Students' packages are encrypted with the public key; only the private key opens them. Create the pair once per semester.

Key id

  1. Download the private key and keep it safe (password manager or an encrypted drive). It cannot be recreated.
    Download lab-private-key.pem
  2. Add it to the private gradebook repository: Settings, Secrets and variables, Actions, New repository secret, name LAB_PRIVATE_KEY, value: the whole file content.
  3. Publish the public key: in the lab repository create the file lab/teacher-public-key.pem with this text.
    Download teacher-public-key.pem Create the file on GitHub

2. Open a submission

Either a submission.json from the gradebook (already decrypted), or a package (from the issue) together with your private key file.
