3D catchment and hourly rainfall-runoff

A hill catchment immediately south-east of VIT Vellore, delineated by Java from the Copernicus 30 m elevation model, with land cover from ESA WorldCover and hourly ERA5 rainfall of Cyclone Fengal (29 November - 3 December 2024). Change the outlet, the rainfall or the soil, press Run simulation, then play the animation.

Educational model. The methods are standard engineering methods (SCS Curve Number, SCS unit hydrograph, Kirpich, time-area), but this catchment has no stream gauge, so the model is not calibrated or validated. Use the numbers to learn how the methods behave, not for design or flood warning. Method and limitations.

What the Java engine does when you press Run

  1. Depression filling (Priority-Flood + ε, Barnes et al. 2014) and D8 flow directions (O'Callaghan and Mark 1984) on the 2 arc-second (about 60 m) grid; flow accumulation in topological order.
  2. Catchment: every cell whose D8 path reaches the outlet; longest flow path L, drop H, slope S = H/L.
  3. Time of concentration: Kirpich (1940), Tc [min] = 0.0195 L0.77 S-0.385.
  4. Runoff generation cell by cell: SCS Curve Number, S = 25400/CN - 254, Ia = 0.2 S, Q = (P - Ia)2/(P - Ia + S) on cumulative rainfall (USDA NRCS NEH-630 Ch. 10).
  5. Routing A: SCS curvilinear dimensionless unit hydrograph (NEH-630 Ch. 16), lag 0.6 Tc, qp = 0.208 A / Tp.
  6. Routing B: distributed time-area translation along the D8 paths with travel times scaled to Tc, optionally followed by a Clark linear reservoir (storage coefficient R). The animation shows routing B.

Source: java/civiltech-core. The same classes run on the JVM (civiltech.lab.Cli) and in the Android app, with identical results.
