What you will find here

Java Lab: type, run, check, submit

Type your program in the page (Java is compiled and run inside your browser), check it against the sample cases, and submit it with your register number while your teacher has the assessment open. Only the teacher can read submissions.

100 real problems to solve

Civil, environmental and climate problems from Vellore and India, each with a recognised method, open datasets, the Java you will practise and what the app should show. Press Claim to start, and Submit when your app is live.

Learn Java from zero

14 lessons (what a program is, int, char, double, arrays, ArrayList and Vector, classes, maps, exceptions) and the 23 BACSE102 lab experiments. Read the explanation, change the input, press Run: the real Java program runs in the page.

3D catchment & hourly rainfall-runoff

A hill catchment beside VIT, built from the Copernicus 30 m DEM and ESA WorldCover, driven by ERA5 hourly rainfall of Cyclone Fengal (Nov-Dec 2024). Java delineates the catchment, computes SCS Curve Number runoff and routes the flow; Three.js animates it.

CivilTech Innovation Starter

One template for every team: introduction page, data input, CSV upload, a Java calculation module, charts, map, optional 3D, results table and automatic deployment to GitHub Pages.

Student project directory

Applications built by student teams, each with its live demo, source code, datasets and team. Teams add their project with a pull request.

Android app from the same Java

The hydrology code that runs in this website is compiled unchanged into an Android app, built automatically by GitHub Actions.

How a student project flows

Identify a problem
Something real on campus or in Vellore: flooding, materials, traffic, water.
Find open data
DEM, land cover, rainfall, OpenStreetMap and other openly licensed datasets with a clear licence.
Algorithm and flowchart
Hand calculation first; then the steps in plain language.
Java module
Pure calculation classes, tested on the JVM.
Web interface
Copy the starter template: inputs, charts, map.
Publish
Push to GitHub; Actions builds and deploys to Pages.
Submit
Pull request to this lab's project directory.
